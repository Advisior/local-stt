# Glossary

| Term | Meaning |
| --- | --- |
| private mode | Timed state, switched on in the menu bar popover (15 minutes, 1 hour, until turned off), in which dictations are output but not stored in `history.jsonl` and pasteboard writes are marked concealed and transient. Stored in `private_mode.json` in the config dir; no file means off, an unreadable file means on. |
